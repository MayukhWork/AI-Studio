# AI3D Studio

AI3D Studio is a local-first AI-assisted 3D scene authoring platform. This repository currently contains the Version 1 Milestone 1 monorepo foundation only. It does not contain application, AI, Blender, or persistence behavior.

## Quality commands

- `pnpm build` — compile workspace packages.
- `pnpm lint` — run static analysis.
- `pnpm typecheck` — run TypeScript checks.
- `pnpm test` — run unit-test infrastructure.
- `pnpm verify` — run the required CI quality gate.

Architecture and implementation planning live in `docs/architecture/`.
